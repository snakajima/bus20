# Paper draft

`main.tex` is the first-paper draft (general LLMs vs Jev, with the Swift
insertion rule and the rollout as classical references). Every number is
taken from a committed results directory under `results/` and says which
one; red TODO marks list what is still missing (held-out runs, related
work, conclusion, affiliations).

Build with `cd paper && tectonic main.tex` (or any TeX Live: pdflatex, bibtex, pdflatex twice).
